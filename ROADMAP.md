# Workflow roadmap

The first delivery covers map placement, opening scenes, moving an actor, and returning to the same map with a tab-local draft. The following examples define completion for the wider editor.

| Area | A creator can finish this workflow |
| --- | --- |
| World and connections | Arrange scenes, draw a gate, choose a destination entrance, then select its connection on the map to reopen the exact source trigger. |
| Scene composition | Assemble a courtyard from a background and tiles, paint impassable walls, place an actor and mark the gate trigger. |
| Behavior | Write a reusable gate script with dialogue, a variable and a condition. Trace both branches and inspect the variable when the actor enters. |
| Assets | Follow an actor to its sprite, edit an animation state's timing, and return to the same selection. Manage backgrounds, tilesets, palettes, fonts, UI graphics, music and sound effects through their references. |
| Hardware and playback | See a palette or tile-budget warning where the change occurs, correct it, preview the scene, then build and play through the gate on a Game Boy Color target. |
| Codex authoring and persistence | Inspect a known revision through MCP and bundled skills, propose a slower walk, preview it on the actor, and accept or discard it. Reconcile a newer revision with an open browser draft before explicitly saving to disk. |
